2. Top 15 Viva Questions & Instant Answers for Students

Q1: What is the purpose of the EventForce Management System?

A: EventForce is a CRM platform designed for Event Planner Solutions to automate event scheduling, client management, venue reservations, vendor assignments, feedback gathering, and cancellation workflows with real-time analytics.

Q2: How is the many-to-many relationship between Event and Vendor implemented?

A: Using an intermediate Junction Object called EventVendor. Each record holds an eventId, a vendorId, and the specific service type provided, allowing an event to have multiple vendors and a vendor to serve multiple events.

Q3: How do you prevent double-booking of venues?

A: In Salesforce, an Apex Trigger (PreventDoubleBooking) checks incoming event dates and venue IDs against existing records. In this web application, the backend API verifies if any non-canceled event exists for the selected venue and date before allowing creation or update.

Q4: What is the Event Cancellation Approval Process?

A: When a user initiates a cancellation, the event enters Pending Cancellation status. An email alert is sent to coordinators. An Event Admin reviews the request: approving it marks the event Canceled and releases the venue back to Available; rejecting it reverts the event to Confirmed.

Q5: What is the Lookup Filter implemented on the Feedback module?

A: As specified in Milestone 4 (Page 28-29 of the PDF), when a client is selected on the feedback form, the Event selector strictly filters to display only events that belong to that chosen client (e.g. Ramesh sees only Ramesh's events).
